# stianaase.no

Personlig nettside for Stian Norgård Aase: musikk og innspillinger, og øvingstavler for lærere under /laerer.

Siden er statisk og publiseres med GitHub Pages på stianaase.no. Den bygges i Stians arbeidsmappe (Google Drive) med
`publiser.py`, og bare filene på skriptets faste liste kopieres hit. Endringer gjøres der, ikke direkte i dette repoet.

Tavlene under /laerer er laget i samarbeid med KI-assistenten Claude. Kilder og lisenser står på /laerer og under
«Til læreren» i hver tavle. Skriftene Fraunces, Figtree, Libre Franklin og Oswald har lisensen SIL Open Font License.
